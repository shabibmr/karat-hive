# Vendor revenue via subscription per Request Type

Vendors pay for Type Subscriptions: a separate entitlement per Request Type (Find An Ornament, Sell Old Gold, coins, bullion). Matching and Offer submission require an active entitlement for that Request’s type, in addition to Verification and Marketplace Access.

**Why.** Revenue without taking a cut of off-platform sales fits the introduction-only model. Per-type products let Vendors buy only the demand they serve and let the platform price liquidity differently by vertical. A single flat “all types” plan would overcharge specialists and undercharge generalists.

**Considered options.** Commission on accepted Offers; lead fees per Request view; one all-access subscription. Commission conflicts with no on-platform settlement truth; lead fees incentivise spam; all-access is less flexible.
