# WhatsApp handoff instead of in-app messaging

Post-acceptance communication uses Talk: a deep link that opens WhatsApp (with web fallback) with the counterparty pre-filled. The platform does not operate an in-app chat product. It may record that contact was initiated; it never accesses conversation content.

**Why.** Both parties already use WhatsApp for business contact in the target market; building messaging would duplicate that channel and create moderation, storage, and support burden without improving settlement (which remains off-platform). The cost is weak delivery guarantees and no platform visibility into deal quality beyond Reviews and Talk usage.

**Considered options.** Full in-app messaging; SMS-only handoff. Rejected for v1 scope and user habits.
