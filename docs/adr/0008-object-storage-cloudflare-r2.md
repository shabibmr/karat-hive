# Object storage on Cloudflare R2, S3-compatible, MinIO for local and CI

Request media, Vendor KYC documents, and processed derivatives are held in **S3-compatible object storage**, never in PostgreSQL (SRS §7.6). The provider is **Cloudflare R2** for hosted environments (staging, production, demo) and **MinIO** for local development and CI. All access goes through the storage port — `presignUpload`, `presignDownload`, `delete`, `head` (`Architecture-Backend.md` §15.3). `docs/Requirements-raw.txt` L102 ("Files Storage -") was left blank; this decision fills it and resolves constraint C-13 (Product Owner, 1 Sep 2026).

**Why.** The MVP needs a zero-cost demo path that does not become a rewrite later. R2's free tier — 10 GB storage, 1M writes and 10M reads per month, and **no egress fees at any volume** — covers the demo outright, and R2 is a production-grade service, so there is no forced migration after launch. It exposes a genuine S3 API, so the adapter is the standard one and the rest of the backend is provider-agnostic. MinIO speaks the same API, so local and CI run without cloud credentials and without a second code path.

**Consequences.** Hosted object bytes moved to **Oracle Object Storage S3 Compatibility** in `ap-hyderabad-1` (`adr/0013`), which supersedes the interim R2 KYC path (`adr/0012`). The S3-compatible port and MinIO-for-local/CI parts of this ADR remain. `ap-hyderabad-1` is India, not UAE; a later swap to a UAE OCI region or another residency-compliant S3 provider stays a configuration change. Production database region remains open in `Architecture-Backend.md` §22.1 (`NFR-020`). The store must support programmatic delete with verifiable completion (`NFR-019`) and encryption at rest plus TLS in transit (`NFR-012`). The three-bucket segregation of SRS §7.6 (Request media / KYC / system artefacts) maps to three private buckets with distinct access policies.

**Considered options.** **AWS S3** — the reference implementation, and `me-central-1` is UAE-resident, but the free tier is 5 GB for 12 months only, so it is not zero-cost for an open-ended MVP; it remains the most likely production target if R2 residency is not accepted. **Backblaze B2** — 10 GB free, S3-compatible, egress free via the Cloudflare CDN; a viable alternative to R2 with the same residency caveat. **Supabase Storage** — 1 GB free and the project sleeps after inactivity; not chosen even though the stack now runs managed PostgreSQL on Supabase (`adr/0009`), because R2's egress-free pricing, larger free tier, and production-grade SLA still win for object storage, and keeping bytes off Supabase avoids concentrating all personal data with one processor. (A `kyc` bucket does currently sit in the Supabase project as a checkpoint-1 convenience — see `docs/checkpoints/` — but R2 remains the production target.) **MinIO only, self-hosted for the demo too** — zero cost and full control, but no hosted URL for a shared demo and another service to run; kept for local and CI, not for hosted environments.
