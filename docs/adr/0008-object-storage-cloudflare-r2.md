# Object storage on Cloudflare R2, S3-compatible, MinIO for local and CI

Request media, Vendor KYC documents, and processed derivatives are held in **S3-compatible object storage**, never in PostgreSQL (SRS §7.6). The provider is **Cloudflare R2** for hosted environments (staging, production, demo) and **MinIO** for local development and CI. All access goes through the storage port — `presignUpload`, `presignDownload`, `delete`, `head` (`Architecture-Backend.md` §15.3). `docs/Requirements-raw.txt` L102 ("Files Storage -") was left blank; this decision fills it and resolves constraint C-13 (Product Owner, 1 Sep 2026).

**Why.** The MVP needs a zero-cost demo path that does not become a rewrite later. R2's free tier — 10 GB storage, 1M writes and 10M reads per month, and **no egress fees at any volume** — covers the demo outright, and R2 is a production-grade service, so there is no forced migration after launch. It exposes a genuine S3 API, so the adapter is the standard one and the rest of the backend is provider-agnostic. MinIO speaks the same API, so local and CI run without cloud credentials and without a second code path.

**Consequences.** R2 places objects by location hint and does **not** guarantee a UAE region. `NFR-020` requires personal data — Vendor KYC documents above all — to sit in a UAE-consistent region for production. That confirmation is an open infrastructure item, tracked in `Architecture-Backend.md` §22.1 alongside the cloud-region decision; it is not blocking, because the S3 port makes a swap to a residency-compliant provider (for example AWS S3 `me-central-1`) a configuration change, not a redesign. R2 supports programmatic delete with verifiable completion, which satisfies the `NFR-019` PDPL erasure requirement. Server-side encryption at rest and TLS in transit are standard on R2 (`NFR-012`). The three-bucket segregation of SRS §7.6 (Request media / KYC / system artefacts) maps to three R2 buckets with distinct access policies.

**Considered options.** **AWS S3** — the reference implementation, and `me-central-1` is UAE-resident, but the free tier is 5 GB for 12 months only, so it is not zero-cost for an open-ended MVP; it remains the most likely production target if R2 residency is not accepted. **Backblaze B2** — 10 GB free, S3-compatible, egress free via the Cloudflare CDN; a viable alternative to R2 with the same residency caveat. **Supabase Storage** — 1 GB free and the project sleeps after inactivity; only worth it if the stack already committed to Supabase, which it has not (PostgreSQL is self-managed per `adr/0007`). **MinIO only, self-hosted for the demo too** — zero cost and full control, but no hosted URL for a shared demo and another service to run; kept for local and CI, not for hosted environments.
