## `E14` / `ADM-INS-02` — ARB migration
- **Now:** setup is correct — `l10n.yaml`, `app_en.arb` / `app_ar.arb`, generated delegates in `MaterialApp.router`, 412 keys (359 getters + 53 parameterized), matching AR key set. But **call-site** use is partial: login, dashboard, taxonomy, vendors, verification, offers, requests, reports use it — typically as `l10n?.key ?? 'English fallback'` rather than required `AppLocalizations.of(context)!`. **No `AppLocalizations` import at all** in: `customers`, `connections`, `abuse`, `audit`, `admin_users`, `announcements`, `moderation`, `settings`, and `kh_admin_scaffold.dart` (nav titles are English constants — `'Dashboard'`, `'Gold Rates'`, `'Soon'`, `'Sign Out'`). Login still hardcodes `'Administrative Portal'` and `'Sign in with Google'` next to ARB fallbacks. No hardcoded-string lint.
- **Do:** move the shell, the 8 un-migrated features, and all dialog copy to ARB. Switch `l10n?.key ?? '…'` to required `AppLocalizations.of(context)!`. Enable the hardcoded-string lint (the mobile workspace already runs it) — turn it on once the sweep is done so it stays clean.
- **Done when:** no user-visible English literal in `lib/`; the lint passes.

## `E24` / `ADM-INS-12` / `ADM-INS-36` / `ADM-INS-63` — accessibility
- **Now:** **zero** `Semantics` / `semanticLabel` / `ExcludeSemantics` in `lib/`. Hit targets: tokens `tableRowHeight: 44`, `buttonHeight: 36`, `inputHeight: 40`; sidebar row **38**; offer Inspect `minimumSize: Size(60, 30)`; table `IconButton`s with 18 px icons. No `SelectionArea` for canvas copy-paste. No in-app find (Ctrl+F is a no-op on canvas). No keyboard Esc / Enter / row focus.
- **Do:** wrap icon-only buttons in `Semantics(button: true, label: …)`. Add `SelectionArea` at the scaffold body. Raise interactive targets to 48 px (pad around a smaller visual — dense tables can stay visually dense). Add a list find field bound to the existing `q` filter. Add a portal `Shortcuts` map (Esc closes dialog, `/` focuses find).
- **Done when:** a screen reader announces every action; every tap target is ≥48 px; `/` focuses find, Esc closes a dialog.

## `ADM-INS-03` — directional layout
- **Now:** physical `Alignment.centerLeft` / `centerRight` on the scaffold and two detail screens.
- **Do:** `AlignmentDirectional` / `EdgeInsetsDirectional` throughout.
- **Done when:** the AR (RTL) build mirrors correctly; no physical alignment in `lib/`.

## `ADM-INS-18` — de-litteralise colours & styles (done here to avoid double-churn)
- **Now:** `Colors.white` / `Colors.black` on action buttons (vendor / customer / request detail, login, verification dialogs); inline `TextStyle(fontSize: 12.0)` on offer list and connection detail.
- **Do:** `context.kh.colors.onPrimary` for button foregrounds; `kh.typography` for text. Add the lint to ban raw `Colors.*` and raw `TextStyle`.
- **Done when:** no raw `Colors.` or bare `TextStyle(` in `lib/` (outside the token definitions).

## `E16` consumers / `ADM-INS-07` / `BR-021` — time display
- **Now:** dates/times are device/local-formatted; `DateTime.now()` used as a parse fallback and age basis.
- **Do:** consume S0's `serverTime` + `Clock`; format instants via `Asia/Dubai` (Gulf Standard Time) for display, store UTC.
- **Done when:** no `DateTime.now()` in `lib/` for ages/fallbacks; timestamps render in GST.
