# Platform Admin screens

**User:** Platform Admin (never self-registers)  
**Platform:** Responsive web Admin Portal (≥ 1280 px)  
**Optimisation:** Queue processing — verification, hold-for-approval reviews, abuse — with keyboard-friendly review without leaving queue context.

## Roles (ADM-S23)

| Role | Capabilities |
|---|---|
| **Super Admin** | All permissions including Admin user management |
| **Operations Admin** | Verification, moderation, user management |
| **Read-only Analyst** | Dashboards and reports only; no mutations |

## Primary destinations

| Area | Screens |
|---|---|
| Dashboard & queues | ADM-S02, ADM-S07, ADM-S16, ADM-S21 |
| Customers | ADM-S03, ADM-S04 |
| Vendors | ADM-S05, ADM-S06, ADM-S07 |
| Marketplace oversight | ADM-S08…S13 |
| Taxonomy & config | ADM-S14, ADM-S15, ADM-S19, ADM-S20 _(deferred)_ |
| Content & ops | ADM-S16, ADM-S17, ADM-S18 |
| Compliance | ADM-S21, ADM-S22, ADM-S23 |

## Unmasked identity

Admins see Customer and Vendor identities unmasked on oversight screens for investigation. KYC document views and bulk personal-data list access are audit-logged.
